# Portfólio Profissional

## Sobre o projeto
Portfólio profissional desenvolvido para a disciplina de **Design Profissional**, orientado pelo Prof. Vinicius Alves Rodrigues. O projeto apresenta minha trajetória acadêmica, competências técnicas e comportamentais, além de projetos práticos desenvolvidos.

## Objetivos
- Apresentar minha identidade profissional de forma clara e acessível.
- Demonstrar competências em desenvolvimento Front-End e Back-End.
- Publicar a aplicação web utilizando o serviço GitHub Pages.

## Tecnologias utilizadas
- HTML5 (Estruturação semântica)
- CSS3 (Estilização com Dark Mode e layout responsivo)
- Git & GitHub (Controle de versão e hospedagem)

## Estrutura do portfólio
- **Apresentação e Sobre Mim:** Resumo profissional e formação.
- **Competências:** Tecnologias dominadas e evidências comportamentais.
- **Projetos:** Demonstração de trabalhos práticos.
- **Currículo:** Download da versão em PDF.
- **Contacto:** Links para perfis profissionais.

## Projetos apresentados
- **Sistema de Login:** Aplicação focada no desenvolvimento web e manipulação de banco de dados SQLite.
